# Files

- [Broadcast - run one command across a group or tag](broadcast.md) - The hosts-tab broadcast wizard (pick a group or tag, enter a command, preview and edit targets) and the background run in src/broadcast with a bounded ssh worker pool, askpass for stored secrets, per-host timeouts, the docked live panel with error toasts and auto-dismiss, cancel, and one audit row per host.
- [Headless CLI - full command tree, JSON output, and exit codes](cli.md) - SSHub's scriptable command-line interface (src/cli) covering hosts, exec, groups with connection defaults, identities, tunnels, SFTP, audit, cross-profile transfer, headless theme checks, import/export/sync, and completions, with --profile selection, --format json, and stable exit codes 0/1/2 (124 for `exec --timeout`).
- [Known Hosts Manager and Host-Key Verification](known-hosts.md) - The identities-tab known-hosts overlay lists and filters SSH host keys with fingerprints and performs guarded removals through ssh-keygen -R (refusing hashed, marker, negated, wildcard and symlinked cases); connect-time host-key decisions go through the explicit y / A keys of the auth modal.
- [Profiles & Themes - switching workspaces, moving data between them, and picking a theme](profiles-themes.md) - User workflows for isolated profiles (startup picker, --profile, the Alt+P profile manager with create/rename/delete/switch and the staged cross-profile transfer) and for color themes (Settings theme picker with live preview, user theme files, and the headless `sshub theme` commands). Internals live in the architecture profiles and themes pages.
- [Session Tools - auth modal, snippets, ghost-text suggestions, command history, and the session log browser](session-tools.md) - The helpers layered on embedded sessions - the interactive SSH authentication modal (src/app/auth.rs), the command snippet library and in-session picker, local-only ghost-text completion from session history, opt-in per-host command history and snippets, and the read-only session log browser with search and bookmarks.
- [Embedded Sessions & SFTP - PTY sessions, session logging, mosh, and file transfer](sessions-sftp.md) - How SSHub runs ssh and local shells inside the TUI via portable-pty + vt100 (src/session), the session switcher and in-session keys, credential delivery through the SSH_ASKPASS channel, the xterm compatibility layer, OSC 52 relay, mouse rules, opt-in session logging with rotation, mosh transport, and the dual-pane SFTP browser with a second-server mode and staged transfer queue (src/sftp).
- [TUI Dashboard - Tabs, Overlays, and Keybindings](tui.md) - The keyboard-driven SSHub dashboard with five tabs (hosts, SFTP, tunnels, identities, audit), the dashboard panel grid, every overlay (palette, session switcher, settings, theme picker, profiles, snippets, log browser, broadcast, keybind editor, help), default keybindings from src/keybinds.rs, and how screens map to AppMode.
- [SSH Tunnels - local/remote/dynamic forwards with keep-alive reconnect](tunnels.md) - SSHub defines and manages SSH tunnels (local -L, remote -R, dynamic SOCKS -D) from the tunnels tab or `sshub tunnel`, spawns them as monitored ssh children with BatchMode/askpass secret staging and group-inherited connection settings, re-syncs the list from the shared database every two seconds, and auto-reconnects keep-alive tunnels with exponential backoff configured in config.toml.
